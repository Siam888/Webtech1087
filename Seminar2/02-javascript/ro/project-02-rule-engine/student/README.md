# Rule Engine

Rulează `npm install`, verificările țintite, `npm run evaluate` (scrie rezultatul în `data/result.json`) și `npm test`. Implementările aparțin doar lui `src/rule-engine.js`.

Folosește README-ul proiectului pentru fluxul IA etapizat. Lucrul începe cu analiza fără editări a formelor regulilor, proprietăților proprii, capturii închiderilor, recursivității și scurtcircuitării, urmată de o schimbare delimitată într-un singur fișier și verificare independentă.
